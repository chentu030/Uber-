# 比 Uber 會算

你以為 40% off 是天上掉下來的珍奶。

然後結帳頁跳出三種隱形加料：**平台每杯貴 8–10 元、服務費、運費**。杯子還沒到手，錢包先被外送員環島一圈。

這是一台手搖最惠計算機。你告訴它店內價、加價、服務費、運費、券怎麼折，它告訴你 **1、2、3、4 杯** 該走路去店裡，還是在 App 裡一次點完。

**現在就打開：** [https://chentu030.github.io/Uber-/](https://chentu030.github.io/Uber-/)

## 這題為什麼有人會算錯

券的文案很甜：*超過 $79 折 40%，你有 4 張。*

大腦的第一反應通常是：

> 那我拆四單，每單折一次，豈不是發了？

數學的第一反應是：你在繳兩次運費。

沒有折扣上限時，兩單各折 40%，加起來還是 40%。折扣不會變多，**服務費 + 運費會再收一輪**。同一批飲料，能過門檻就併一單。4 張券留給下次口渴，或留給「單張最高折抵 $60」這種會卡關的券。

運費才是翻盤的那一票。預設店內 $55、平台 +$9、服務費 $15：

| 運費 | 2 杯 Uber 一次點 | 2 杯走路去店裡 | 贏家 |
| --- | --- | --- | --- |
| $0（會員免運） | $91.8 | $110 | Uber，省 $18.2 |
| $15 | $106.8 | $110 | Uber，險勝 |
| $25 | $116.8 | $110 | **店內**，少花 $6.8 |
| $35 | $126.8 | $110 | 店內，少花 $16.8 |

大概 **運費超過 $18**，兩杯就不要點外送了。三杯、四杯比較容易把雜費攤薄。一杯？走。平台價過不了 $79，券只是櫥窗。

## 怎麼用

1. 填店內單價（或點 $45–$75）。
2. 選平台加價 $8 / $9 / $10。
3. **服務費、運費分開填。** 會員免運就按「免運」。拆單會再收一次，不要騙自己。
4. 有最高折抵就選上限；沒有就維持「無上限」。
5. 看四張小票。螢光框是今晚最不虧的點法。

公式就一行：

```
Uber 一單 = 平台小計 − 折抵 + 服務費 + 運費
店內一趟 = 杯數 × 店內價
```

折抵要先過門檻，再取 `min(小計 × 40%, 上限)`。

## 預設假設

- 店內 $55，平台每杯貴 $9
- 超過 $79 才能折（不是「滿 79」；App 若這樣寫，頁面上有開關）
- 折扣 40%，手上 4 張券
- 服務費 $15 / 單，運費 $25 / 單
- 可以走路去店裡拿。關掉這個開關，就只比較 Uber 怎麼拆

數字是常見手搖，不是你家對面那間的官價。以結帳頁為準。

## 本地打開

這是靜態頁，不要 npm，不要 webpack，不要再安裝一個框架來算珍奶。

```bash
git clone https://github.com/chentu030/Uber-.git
cd Uber-
```

用瀏覽器打開 `index.html`，或：

```bash
python -m http.server 4173
```

然後去 `http://localhost:4173`。

GitHub Pages 走 `main` 分支，workflow 在 `.github/workflows/pages.yml`。

**一杯走路。兩杯先看運費。三杯以上才比較像外送的主場。拆單之前，先問自己是不是想付兩次運費。**
